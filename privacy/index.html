Privacy notice

Last updated: October 2026. This notice describes the forms and basic server operation implemented on this website.

Information submitted in forms

The contact form asks for your name, email address, an optional company, message, and consent to use the details to reply. Product update requests ask for an email address, optional name, and consent to receive a response about the request. The forms include an anti-spam honeypot. We do not run an automated mailing list or store form submissions in a website database; submissions are sent as email notifications to hello@sgsaitechnology.com when server mail is configured.

Email messages may remain in the recipient’s mailbox, backups, and mail provider systems. No fixed deletion or retention schedule is configured by this website, so retention depends on mailbox and provider settings. Ask us to delete a message or stop follow-up by emailing hello@sgsaitechnology.com.

Operational logs

The web server and hosting platform may process request metadata such as IP address, requested URL, time, and response status for delivery, security, and troubleshooting. Hosting-provider log access and retention are controlled by the deployment configuration and provider; this site does not currently define a separate log-retention period.

Cookies, analytics, and third parties

This site records a minimal first-party pageview event for public pages. The browser sends only the page path; the server records that path and a timestamp in its application logs. The analytics event does not include an IP address, query string, referrer, user agent, cookie, or visitor identifier. Hosting and network logs may separately process request metadata such as IP address for delivery and security. Log retention is controlled by the hosting configuration and provider. This site does not set analytics or advertising cookies, load third-party font services, or show a cookie banner. Typography uses local system fonts. Email delivery is handled by the SMTP service configured by the site operator; that provider may process message metadata and content under its own terms and retention settings.

Your choices and questions

You can choose not to submit a form and instead contact us by email. To ask about, correct, or request deletion of information you submitted, contact hello@sgsaitechnology.com. Verified legal-entity, jurisdiction, and office-address details are not currently published here; seek qualified advice for legal rights that depend on those details.
